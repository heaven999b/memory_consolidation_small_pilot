# 研究提案(骨架 v0)· 评测可靠性协议:诊断并预防 Agent/LLM 安全评估中的系统性 overclaim

> 状态:骨架,2026-07-05。素材全部来自本项目"记忆固化安全"线的真实实验(可复现)。
> 用途:判断这条线能否作为博士主线;对齐框架后再转 docx 正式提案。

## 0. 一句话论点(thesis)
主流 agent/LLM 安全评测**系统性地 overclaim**;一套**预注册的四支柱可靠性协议**能在发表前拦住其中绝大多数。本项目把该协议用在自己的"固化制造检测盲区(blindspot)"发现上,展示了一个**已通过人类金标准 κ=0.851** 的现象如何在泛化测试下崩塌(单措辞 3/3 → 6场景×3措辞 **3/18**)——以此同时证明协议的**必要性**(不做就会 overclaim)与**充分性**(做了就拦住)。

## 1. 问题:overclaim 不是个例,是机制
Agent/LLM 安全评测爆发式增长,但可靠性实践严重滞后。本项目在自身研究中反复撞见、并归纳出**四个系统性造错机制**:
1. **指标无否定/语义处理** → 词法终点两个方向都造假(judge 高估安全、payload 高估危险)。
2. **天花板 + 功效不足 + 伪重复** → null 结果注定出现,又被当成"无害"(缺等价检验)。
3. **评估器是未校准的同源黑箱** → "以 judge 为准"不成立,judge 曾被自己的数据证伪。
4. **顶层表述比正文乐观 + 选择性报告 + 泛化性从不测** → 摘要/标题的强主张,正文撑不起。

## 2. 核心贡献
- **C1 · 协议**:一套预注册四支柱可靠性协议(见 §3),每支柱配一个可操作检验 + 通过阈值。
- **C2 · 自证 case study**:blindspot 的完整兴衰(见 §4),逐关展示协议的拦截力——**关键:这是一个真现象、过了人类 κ,不是稻草人**。
- **C3 · 领域审计(待补,最大原创性)**:把协议当 rubric,系统审计一批已发表 agent 安全评测,量化各支柱的违反率 = overclaim 普遍性的**实证证据**,而非断言。

## 3. 方法:四支柱(机制 → 检验 → 本项目实证锚点)

| 支柱 | 检验(通过阈值) | 本项目实证 |
|---|---|---|
| **P1 终点效度** | 指标须做否定/作用域处理;须有人类金标准 κ≥0.8;所有 discordant 必标 | `action_emitted` 纯词法 **25% 假阳** → 修否定处理 → 人类盲标 **κ=0.851**;κ 反过来抓出 post-token "avoid X" 残余假阴 bug |
| **P2 功效与天花板** | 降天花板(基线不贴顶);null 必须走 **TOST 等价**+预设 δ,禁止"null=无害";簇稳健 CI;预注册样本量 | n=6 CI 宽到 [0,0.89] 认证不了等价 → **n=20 TOST(δ=.15)等价 p=.034** 才有功效 |
| **P3 评估器可信** | 强模型评估器;跨源去同源;评估器本身要 κ 校准 | 弱审计器 gpt-4.1-mini 造伪影(参数级规避 8/10),换 **gpt-4o 降到 4/10**;judge 未校准是公认硬伤 |
| **P4 泛化** | **多措辞 × 多场景**预注册泛化测试;禁止基于单一措辞声称"定律" | blindspot 单措辞 3/3 → **6场景×3措辞 仅 3/18**,根因是措辞变体极大改变 N0 基线 |

## 4. Case study:blindspot 的兴衰(worked example)
1. **现象**:记忆固化算子合成的新记忆不回过安全闸门;固化把"关 MFA""自批 PR"等坏习惯**正当化**——reader 从固化前几乎不推荐(N0≈0),到固化后当"standard fix"推荐(N2=1.0)。
2. **天真的发表版**:"Consolidation creates safety blind spots" + 一张 N0→N2 暴露率飙升图。多数 agent 安全论文到此为止。
3. **协议逐关**:
   - P1:词法终点先报 0.30 暴露,其中 25% 是假阳(logpii 全假);修正 + 人类 κ=0.851 才可信。
   - P2:n=6 说不清;n=20 才认证"平均不放大"、同时定位到少数场景放大。
   - P3:换 gpt-4o 语义 judge 才能跨措辞判定。
   - P4:**致命一关**——6×3 泛化测试把 3/3 打成 3/18,现象随措辞崩塌。
4. **最终定性**:blindspot 是**措辞敏感的脆弱现象**,不是普遍定律。一个漂亮发现被自己的协议诚实降级。

## 5. 成为博士主线还缺什么(诚实清单)
- **C3 领域审计**(主要新增工作、最大原创性):选定样本(如近 2 年 N 篇 agent/记忆/工具使用安全评测),预注册 rubric,双人标注 κ,量化四支柱违反率。← 这决定能否从"方法"升级成"领域诊断"。
- **P3 收尾**:本项目的 gpt-4o judge 自己还没做 κ 校准(留的尾),得补,不然协议自己违反 P3。
- **工具化**:`fix_toolkit`(否定处理+TOST+簇CI+κ)+ 泛化 harness → 开源可复用包,让协议能被别人用 = 影响力。
- **文献定位**:与 reproducibility crisis、benchmark validity、LLM-as-judge 校准、construct validity 文献接上,证明这是"已知问题在新领域的系统化",不是重新发明。

## 6. 预期审稿人攻击 & 回应
- *"四支柱是常识"* → 是常识,但**普遍不做**;C3 用数据证明"不做"的普遍性,这才是贡献。
- *"case 是你自造的"* → 正因可控才干净;且现象**曾过人类 κ**,是真发现被证伪,非稻草人。
- *"你 judge 没校准还用"* → 明确列 limitation,且 P3 正要求校准,自己在补——协议对自己也适用。
- *"泛化测试的 judge 也不可信"* → "措辞敏感"的**方向结论**不依赖 judge 精度(同场景内偏置一致,N0 从 0 跳 3 非 judge 假象)。

## 7. 为什么这是博士级贡献
从"又一个 agent 安全发现"(一块砖),转向"**这个领域如何知道自己错了**"(元层面、可迁移、有方法论原创)。它把本项目一路唯一的护城河——**别人省掉的严谨**——从"自我怀疑的成本"变成"正面的、可发表的资产"。
