# 第一部分:引发研究的动机

## 1.1 引发点
自进化 / 长跑 agent 的**标准记忆固化配方 = "只把判对的轨迹写进记忆"**(picky consolidation;SkillOS 2605.06614、标准四阶段 refine-by-filtering、Mem-π)。社区**一直把它当提准确率的杠杆**(2602.01966 明写"评测指标就是任务成功率")。**没人问过:这个删失失败样本的默认操作,会不会顺带扭曲 agent 对「自己」的估计。**

## 1.2 转念(机制内核)
一个 agent 对"我能否解下一题"的隐式估计,本质是它记忆里**可见成功率**的读数。**只留成功 = 对自我能力样本做右删失采样**(抹掉会压低自估的失败证据)→ 按删失基率(→1.0)高估自己。且这个膨胀是**难度选择性**的:易题真实基率本就高→不误导;难/OOD 题真实基率低但记忆全成功→高估 gap 张开。命名 **Censored-Base-Rate Inflation of the Self-Model**。

## 1.3 一句话母题
**只留成功的记忆选择 → self-model(不是 world-model / skill)误校准 → 可归因决策损失;机制 = censored base rate,补回被删失的失败基率能纠正。**

## 1.4 因果链
```
按成功结果挑记忆 →(censored base rate)→ self-model 高估(self通道·难度选择性)
→ "直接答/用工具/放弃"选错 → 损失本可得分数(公开完整统计可纠正)
```

## 1.5 全研究一句话立意(v3)
不止"发现只记成功会致高估",而是:**给出一个能定量预测任意记忆策略自我误校准的变量,把这个高估解剖成几种可分离的失败模式,证明机制是删失基率(补回即纠正),并揭示一整批现有记忆固化方法与现有纠偏方法都在这个新轴上系统性失效。**

# 第二部分:五个 RQ 及其 Baseline 设计

逻辑链:**存在(RQ1)→ 结构(RQ2)→ 规律(RQ3)→ 机制(RQ4)→ 影响+破旧方法(RQ5)**,环环咬合。

## 2.0 数据与材料总纲(所有 RQ 共用;回答"数据匹配吗、是不是 AI 合成")

**结论:全程零 AI 合成。题目/判分用现成公开数据+确定性程序;唯一需自己产的是"真实历史日志",那是被测模型在公开题上真跑的观测,不是编造。**

### 2.0.1 三层来源
| 层 | 来源 | 现成公开 or 自己产 | 是否合成 |
|---|---|---|---|
| 题目 | 数学竞赛原题(年份+题号+官方答案)/ 轻量代码 LiveCodeBench;生态复现留 SWE-bench-Live | 现成公开 | 否(禁 LLM 造题) |
| 判分 | 官方测试 / 答案 exact-match / 环境状态 | 确定性程序 | 否(禁 LLM 判对错) |
| 难度 | 模型"无记忆+强制直答/用工具"真跑的真实通过率 | 自己跑 | 否(禁 LLM 标) |
| 历史/记忆 ⚠️ | 被测模型在公开题上真跑的日志 (task, trajectory, reward∈{0,1}) | 自己产(无现成数据集) | **否**——真实观测非 fabrication |
| 记忆抽取 | 固定代码+随机种子 | 确定性程序 | 否(禁 LLM 挑) |

### 2.0.2 匹配性确认
**匹配。** 本研究测 self-model 的难度选择性偏移,对数据的三个硬要求现有选型全满足:①确定性判分(数学exact-match/代码测试);②真实宽难度梯度(易近满、难近地板,给出可测的选择性空间);③可溯源+可时间切分(held-out/OOD)。
**⚠️ 红线:题目必须非饱和。** 用 GSM8K 这类近全对的题→梯度塌→gap 无处张=数据不匹配(重蹈"GSM8K 自进化假")。故主池锁 MATH L1–L5 / 竞赛题。

### 2.0.3 通用约定
作答前冻结自估与动作(固定 JSON 字段);**self-report 只当被测变量,ground truth = 确定性 empirical success**;主探针行为式(下注/effort/pairwise),规避 verbalized 恒定坑,verbalized 仅辅助。所有组从**同一份真实历史日志**取记录;时间切分保证测量题晚于历史题、同题不跨池、去重不用 LLM。

## RQ1 —— 存在性 + 通道解离(命脉打底)

**问题**:只记成功,是否**因果**制造针对"自己能力"(而非对世界)的高估?——self 动、world 平。

### 主方案(baseline)
**T1 只留成功 vs B2 分层随机保留(matched)**,主指标 = self 探针的 signed over-confidence gap(揭示自估 − 确定性 empirical success),按难度带 × seen/held-out 分层。B2 已匹配数量/题型/难度/动作/时间/文本长度,残差归因 selection-by-correctness。

### 核心备选(一起跑)
| 备选 | 跑什么 | 作用 |
|---|---|---|
| B-1 锚点谱 | B0 无记忆 / B1 全历史 一起跑 | 画完整 B0→B1→B2→T1 谱,定位效应在谱上的位置 |
| B-2 通道三探针 | self 探针 + world 探针(同题客观事实/别的模型能否解)+ 无关概率题 | 证 **self 动 world 平**(命脉腿) |
| B-3 归因操纵 | "这是你的历史" vs "这是别人的历史" | 证 self-attribution 特异,排除泛化 few-shot 锚定 |
| B-4 探针交叉 | 行为式(下注/effort)为主 + verbalized 为辅 | 交叉验证,躲 verbalized 恒定坑 |
| B-5 技能等效性(前置门) | 强制直答 / 强制用工具 测真实通过率 + TOST | 证 T1/B2 真实能力等效,排除真能力退化(2605.09315) |

### 扩展备选(加分)
多 proxy 模型复现;seen 分布内也放一组同难度题看 gap 是否确实不张(易带安慰剂)。

**数据**:数学 L1–L5 / 竞赛题(现成公开);历史日志自跑;exact-match 判分。
**可证伪**:难带 gap(T1)−gap(B2) 的 CI 含 0 = few-shot per se;易带同等张 = 笼统自信;world 也动 = 泛化偏移;被 raw accuracy 全解释 = skill 非 metacognition。任一成立则本 claim 相应降级。

## RQ2 —— 失败模式解剖(升级 B)

**问题**:这个高估,由哪几种**可分开**的具体毛病构成?——把笼统的"高估"解剖清楚。

### 主方案(baseline)
测"**高估水平**"支的四种签名,各配诊断探针,并做**可分离性检验**:
| 签名 | 诊断探针 |
|---|---|
| 基率遗忘 | 补回 N/S/F 是否纠正(接 RQ4) |
| 难题盲 | 难带 gap ≫ 易带 gap |
| OOD 外推 | 把 seen 成功率错迁到 OOD 的量 |
| 归因错配 | 你的历史 vs 别人的历史(接 RQ1 B-3) |

### 核心备选(一起跑)
| 备选 | 跑什么 | 作用 |
|---|---|---|
| B-1 **过度笃定支** | 除估值外,测报告的不确定性/区间宽度是否变窄(overprecision):让模型给置信区间,或多次采样看方差 | 补上正交的一支(和 RQ4 目标分解咬合) |
| B-2 可分离性分析 | 四(五)签名的相关矩阵 / 因子分析 | 证它们真独立、不是一个东西换名 |
| B-3 单诱因 ablation | 逐个关掉诱因(删失/难度/分布/归因)看对应签名是否消失 | 建立签名↔诱因的因果对应 |

### 扩展备选(加分)
"高估自己胜过别人"支(better-than-average 探针);动态承诺升级(连续决策序列里高估是否累积)。

**数据**:同 RQ1;OOD 用同源但题型外的公开题。
**可证伪**:若签名高度相关/无法分离 → 解剖失败,只报单一"高估"指标;若某签名的 ablation 不改变它 → 该签名↔诱因对应不成立。

## RQ3 —— 关键变量 + 预测律(升级 A;理论分量最高)

**问题**:能否用**一个变量**定量预测高估多强,并**外推到没测过的记忆策略**?

### 主方案(baseline)——贝叶斯后验偏差
建"理性 agent 应有的后验"基准:先验(对难度的信念)+ 似然(记忆里可见成功/失败)→ 后验。**理性后验看到"K 条全成功但 K 小"会收缩、不跳到 100%**。主指标 = 实际自估**偏离理性后验的量**。两种先验对比一起跑:**无信息先验**(纯读可见成功率)vs **带难度先验**(难题该下调)——看实际 agent 更像哪个(若像前者,给"难题盲"一个贝叶斯解释:它没用难度先验)。

### 核心备选(一起跑,同批数据多种拟合三角验证)
| 备选 | 跑什么 | 作用 |
|---|---|---|
| B-1 描述回归 | 高估 ~ Censoring Gap(=可见成功率−真实基率)× 难度;单调趋势+斜率+CI | 稳健打底,不依赖建模假设 |
| B-2 删失生存分析 | 把"只留成功"建成右删失采样;比 agent 估计量 vs 删失校正估计量 | 机制统计学化,证 agent≈"忽略删失的 naive 估计量" |
| B-3 分层贝叶斯联合拟合 | 多历史×多难度×多档联合估 agent 专属"删失易感度"参数+CI | 给可比较模型的单标量 |
| B-4 外推检验 | 留一法:部分策略拟合、预测留出策略的高估 | 验证"可外推"(接 RQ5 咬合) |

**多做法一起跑的价值**:若 ①②③ 都指向"agent 忽略样本量/忽略删失",结论极硬;若分歧,揭示它到底保留了哪部分理性。

**数据**:φ-sweep 各档全来自真实历史(禁伪造成/败);难度用真实通过率。
**可证伪**:agent 若根本不做后验更新(主方案退回描述回归都无关系)→ 预测律不成立;B-4 外推若失败(留出策略预测不准)→ 只报描述性、不声称可外推。

## RQ4 —— 机制闭环(补回删失能否纠正)

**问题**:补回被删掉的失败,能否纠正高估?——证明祸根就是删失基率。

### 主方案(baseline)
**M1 成功卡+公开完整统计(N/S/F+按动作拆分) vs T1**;**M0 成功卡+等长中性文字**排除"提示变长"。数字全由程序从真实历史日志统计。

### 核心备选(一起跑)
| 备选 | 跑什么 | 作用 |
|---|---|---|
| B-1 干预强度谱 | 给数字 vs **把删掉的失败案例插回记忆** vs 元认知提示 | 测"数字重要还是具体失败案例重要" |
| B-2 双向验证(证特异性) | 注入**假的更高**成功率 → 应进一步抬高 | 证 agent 真在读这个数字,不是笼统变谨慎 |
| B-3 纠正目标分解 | 分别测干预对 估值/过度笃定/决策 各纠正多少 | 揭示"哪种毒最难解"(接 RQ2 B-1) |

### 扩展备选(加分)
剂量化纠正:补回失败 0/半/全,看纠正是否成比例。

**数据**:成功卡内容不变;N/S/F 程序统计(非 LLM 估)。
**可证伪**:M1 不纠正 或 M0 同样纠正 → 不能声称"隐藏失败数量"是机制,机制名降级;B-2 注入假高不抬高 → agent 未读该数字,机制解释存疑。

## RQ5 —— 新场景 + 破旧方法 + 决策危害(升级 C;最大 impact)

**问题**:在这个新评测轴上,现有主流记忆方法与现有纠偏方法是否**系统性失效**、造成可归因决策损失?

### 主方案(baseline)——Self-Calibration-under-Censoring 评测轴
把现有主流记忆固化方法各自固化记忆,统一测注入的 self-miscalibration + 确定性决策损失,排"删失易感度榜":success-only filtering(SkillOS)、score-based retention、reflection-based(Reflexion)、Self-Consolidation(2602.01966)、recency-K、reservoir、全历史+公开统计。**预测:按结果/分数挑的方法(success-only/score-based/reflection)集体翻车;保基率的(reservoir/全历史+公开统计)幸免。**

### 核心备选(一起跑)
| 备选 | 跑什么 | 作用 |
|---|---|---|
| B-1 **咬合 RQ3** | 把每个方法投影到 Censoring Gap,用 RQ3 的律预测其翻车程度 | 律能跨方法外推则同时验证 RQ3+解释 RQ5,结构自洽 |
| B-2 即插即用修复 | 给每个方法加"公开删失统计"层,测是否普遍降低 miscalibration | 从"揭露问题"升到"给药方" |
| B-3 现有纠偏 fix 失效 | 跑 abstention/calibration fix(2607.10738 / 2601.07264)在删失记忆下:观察式+机制式(上游改记忆 vs 下游修决策) | 证"毒在上游、它们修下游" |
| B-4 决策危害三分支 | 强制直答 / 强制用工具 / 自由选择 + M1 下自由选择 | 确定性决策损失 = 最优动作期望分 − 实选动作期望分;修复能否降损 |

**数据**:判分全确定性;奖励/成本预注册固定;现有方法用其公开可复现实现(非合成)。
**可证伪**:现有方法**没有**集体翻车(结果杂)→ 叙事降级为个案;B-1 律不跨方法外推 → RQ3/RQ5 咬合断,各自单报;B-3 现有 fix 在删失下仍有效 → "上游中毒"论点不成立。

# 第三部分:每个 RQ 的增量与相似工作(novelty 对比,放最后)

> 诚实前提:**没有单条 RQ 是"明显强增量";novelty 是组合级的,靠环环咬合。** 逐条:

| RQ | 增量(大白话) | 有没有人做过(最接近工作) | 诚实强度 |
|---|---|---|---|
| **RQ1** 存在+通道 | 高估的是"对自己"(非对世界),self/world 双探针分开证 + 归因特异 | overconfidence 测过但无记忆成因/无 self-world 分离(2602.06948);memory→自信→危害模板被占但 world 通道(2606.29279 / 2605.29463);自我意识仅静态测(KAPRO 2606.20661) | 中(打底,靠 self≠world) |
| **RQ2** 失败模式解剖 | 把笼统"高估"解剖成可分离签名(含 overprecision 过度笃定支) | 没人把记忆致高估解剖成可分离模式;现有当单一数字测 | 中(诊断/分类贡献) |
| **RQ3** 关键变量+预测律 | 提出可外推变量(Censoring Gap)+ 贝叶斯后验偏差基准,回答"是不理性还是用错先验" | 没人给出预测记忆致误校准的定量可外推变量;dose-response 没人做;rate-distortion(2605.10870/2607.08032)是 compression→决策质量、非自我估计变量 | **中强**(理论分量最高) |
| **RQ4** 机制闭环 | 补回删失即纠正(+双向验证+目标分解)→ 钉死机制=删失基率 | Honest Lying(2605.29463)有 fix,但针对"存错内容"、world 通道 | **中强**(钉机制;方向可预期) |
| **RQ5** 新场景+破旧方法 | 新评测轴让一批现有记忆方法集体翻车 + 现有纠偏 fix 上游中毒失效 + 即插即用修复 | 现有固化方法(2602.01966 等)全当提准确率用、没测自我校准副作用;现有纠偏(2607.10738 / 2601.07264)假设自估可信、没测删失下失效;memory→决策危害被占但 world 通道(2605.24941 / 2607.01071) | **强**(scoop 覆盖不到) |

## 3.1 整体质量判断
五条各有独立增量、逻辑不重叠且互相咬合(RQ2 难题盲/过度笃定 ↔ RQ3 贝叶斯先验/后验 ↔ RQ4 目标分解 ↔ RQ5 用 RQ3 律解释翻车)。**真正抬起论文的是 RQ3(预测律)+ RQ5(破旧方法)**——scoop 未覆盖;RQ1/RQ4 打地基守机制,RQ2 偏诊断。加上 A/B/C 后,从"发现现象(比一比)"升级为"**现象→拆解→定量律→机制→干翻现有方法**"的完整体系,已是立得住的 CCF-A 骨架。

## 3.2 最威胁论文与防御
**2605.29463 Honest Lying**(同款因果 wipe-ablation+下游 harm+专用指标,只差信念通道)——RQ1 的硬 self≠world 控制是唯一防线。**绝不 lead 在"manufactured confidence"(2606.29279 占,会塌到 ~25%)**。

## 3.3 必引清单
2606.29279 · 2605.29463 · 2606.20661 · 2602.06948 · 2605.24426 SEAL · 2605.30159 MMPO · 2605.06614 SkillOS · 2605.09315 · 2605.24941 · 2607.01071 · 2607.10738 · 2602.01966 · 2601.07264 · 2605.10870 / 2607.08032。(前三为非谈判必引。)

## 3.4 诚实评估 + 风险
- **母题 ~55% still-novel**(conditional on execution),加 A/B/C 后上行,主要靠 RQ3+RQ5。
- **每条新做法有独立翻车路径**(RQ2 签名分不开 / RQ3 不可外推 / RQ5 现有方法不集体翻车),全进预注册停止表。
- **最大 load-bearing 前置**:frozen 模型是否真从 in-context 记忆读基率调自估?→ **阶段 0 manipulation check(读基率 + 概率不饱和)是生死前提**,不过不进主实验。

# 附:执行顺序(主+备选一起跑,但分阶段)
- **阶段 0** 验测量流程(读基率/不饱和/拟合难度曲线/冻结 K·φ档·种子·可忽略能力差异·奖惩)。
