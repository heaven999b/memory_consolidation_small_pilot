# Weekly Reports

This directory contains reader-facing weekly updates that are safe to share as compact progress summaries.

Each week now lives in its own folder so the front page stays clean while the supporting tables, dashboards, and explanation notes stay next to the report that cites them.

| Week | Audience | Entry point | Includes |
| --- | --- | --- | --- |
| Week 1 | External readers / handoff readers | [week1/](./week1/) | Main report, metric guide, artifact index, supporting materials |

## Notes

- These reports are intentionally shorter and cleaner than the internal research notes.
- For code-level mapping, use [research_question_map.md](../docs/research_question_map.md).
- For the most current research caveats, use [RESEARCH_README.md](../RESEARCH_README.md).
