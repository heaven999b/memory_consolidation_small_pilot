# Identifiability of Memory-Operation Culprits under Provenance Restoration — Complete Proof · 2026-07-13

> C1 的理论腿。模型定理:在理想化管线假设下,给出记忆失败的责任 op 何时唯一可识别、membership 与 restore 归因的可识别性差、以及 merge 节点的歧义界。**紧咬实证**:定理 2 = "restore 在干扰下失效、membership 仍 sound"(实测 restore 28% vs membership 55%);命题 3 = unresolved / store-check 误差来源。

## 1. 模型与假设

查询 `q` 有唯一 gold 支撑事实 `e`。记忆管线 `Π = W → C → R → A`(写入/固化/检索/回答)。定义各阶段**存在指示**
`p_W, p_C, p_R ∈ {0,1}`:e 的**答案相关内容**是否可从该阶段的记忆状态恢复。约定源含 gold,故 `p_0 = 1`。

- **(A1) 管线单调性**:固化只读写入记忆(`M_C = C(M_W)`),检索只从库里选(`X_R ⊆ M_C`)。故
  `p_W = 0 ⟹ p_C = 0`,`p_C = 0 ⟹ p_R = 0`,即 **`p_R ≤ p_C ≤ p_W`**。
- **(A2) 忠实答复者**:`A` 答对 `⟺ p_R = 1`(无幻觉答对、无干扰主导)。
- **(A2′) 干扰主导答复者**:上下文含竞争记忆 `d`(对 `q` 断言错值);只要 `d ∈ X_R`,`A` 输出 `d` 的错值,**不管 e 在不在**。(建模自信答错。)
- **(A3) 理想成员检查**:检查返回 `p̂_k = p_k`。(理想化;§5 推论处理带噪。)

**定义**。*失败* = `A` 答错。*责任 op* `κ(q)` = 存在性首次跌落的阶段:`κ = min{ k ∈ {W,C,R} : p_k = 0 }`(管线序 `W<C<R`)。
- **Membership 归因** `M`:输出第一个 `p̂_k = 0` 的阶段。
- **Restore 归因** `R`:干预 `ρ_s` 强制 e 在阶段 `s` 存在并重跑下游;`ρ_s` "修好" = 重跑答对。

## 2. 单调性与元凶唯一

**引理 1(单调性)**。A1 下 `(p_W, p_C, p_R)` 非增。*证*:即 A1 两条蕴含的逆否 `p_R ≤ p_C ≤ p_W`。∎

**命题 1(元凶良定义且唯一)**。A1 下,对*证据丢失型*失败(`p_R = 0`),序列 `(p_0{=}1, p_W, p_C, p_R)` 是从 1 到 0 的非增 0/1 序列,**恰有一个 1→0 跳变**,故 `κ` 存在且唯一。*证*:非增二值序列由 1 起、以 0 终,必有唯一首零位;`κ` = 该位。∎

**失败分型(A2′ 下,重要)**。A2 下失败 `⟹ p_R = 0`(证据丢失),op 归因良定义。A2′ 下失败分两类:
(i) **证据丢失**(`p_R = 0`):`κ` 良定义;(ii) **干扰主导**(`p_R = 1` 但 `d` 压倒 e):**不是任何单一 op 丢证据造成的**,op 归因对这类**不适定**(元凶是 d 的存在,非某 op)。⟹ *op 归因只对证据丢失型失败良定义*——这是范围声明,必须写进论文。

## 3. 主定理

**定理 1(Membership 可识别,答复者无关)**。A1、A3 下(A2 或 A2′ 均可),对证据丢失型失败,`M` **精确返回 `κ`**。
*证*:`M = argfirst_k p̂_k{=}0 =`(A3)`argfirst_k p_k{=}0 =`(命题 1)`κ`。`M` 只读存在性 `p`,**与答复者行为无关**,故 A2 或 A2′ 下同样成立。∎

**定理 2(Restore 的可识别性缺口)**。
**(a) 忠实下 sound**:A1、A2 下,restore 识别 `κ`——`ρ_R`(注入 e 进上下文)使 `p_R{=}1`,由 A2 必修好;修好模式 `{ρ_R 修;ρ_C 修 ⟺ 重检索后 e 入上下文;ρ_W 修 ⟺ 重跑管线保 e}` 唯一决定 `κ`。
**(b) 干扰下 unsound**:A1、A2′ 下——
  - 对*干扰主导型*失败:任何 `ρ_s` 后 `d` 仍在上下文 ⟹ `A` 仍输出 d ⟹ **无 restore 修好** ⟹ `R` 判 "unresolved",**无法识别**;
  - 对含 d 的*证据丢失型*失败:`ρ_R` 把 e 加入但 `d` 仍主导 ⟹ `ρ_R` 不修 ⟹ `R` **误判**。
  故 A2′ 下 restore **不 sound**;而 `M` 仍 sound(定理 1)。∎

> **定理 2 = 实证的形式解释**:自信答错(干扰)regime 下,restore-修答案信号失效(实测修复 28%),membership 存在性信号仍 robust(实测 55%)。**这把"经验发现"升成"定理预测"。**

## 4. Merge 歧义

**命题 3(merge 歧义界)**。固化是多对一合并:源集 `S(e) ∋ e`(fan-in)压成摘要 `σ`。设 `p_C = 1 ⟺ σ 对 q 答案相关地决定 e`。若合并**非分离**——即存在共并干扰 `d ∈ S(e)`、其答案相关支撑与 e 重叠,使 `"σ 决定 e" ⟺ "σ 决定 d"`——则 `p̂_C` 无法区分"e 被保留"与"d 被保留",`κ` 只可识别到歧义集 `𝒜 = {C-丢-e, C-换成-d}`。**界**:不可解比例 `≤ Pr_q[ e 与答案重叠的干扰共并 ]`。∎

> **命题 3 = unresolved 率与 store-check 误差的来源**:merge 纠缠越多,归不出/误判越多。

## 5. 带噪检查推论

**推论(带噪 membership)**。若各阶段检查独立以 `ε` 出错(`p̂_k ≠ p_k`),则 `M` 仅当 `κ` 及之前某阶段检查翻转时出错:`P(M ≠ κ) ≤ 1 − (1−ε)^{depth(κ)} ≤ 1−(1−ε)^3`。*证*:`M` 的首零位仅由 `κ` 位及其前各位决定;任一翻转才可能移动首零位;独立性 + 并界。∎

> **推论连回实证**:write-check 精度 84%(ε≈0.16)、几何 store-check 更准——推论把"检查精度"直接翻译成"归因精度上界",指导该优先加固哪个检查。

## 6. 定理的作用(为什么它不是装饰)

| 定理/命题 | 预测的实证现象 | 论文里的作用 |

## 7. 诚实边界

- **模型定理**:A1-A3 是理想化(真固化非二值存在、检索非确定、答复者非 A2/A2′ 二分)。定理给的是**该模型下**的可识别性;benchmark 的作用正是**实测这些假设何时成立/破裂**(理论与实验互为验证)。
- 命题 3 依赖一个 merge 模型的形式化,当前以"有界命题"给出;完整版需定义 σ 的答案相关坐标与分离性度量。
- 这是 C1 的**合格理论腿**(解释实证、界清范围),非深定理;深化方向 = 把 merge 分离性做成可测度量、给紧界。
