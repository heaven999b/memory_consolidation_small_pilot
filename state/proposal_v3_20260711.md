# Proposal v3(定稿)· 2026-07-11

> 演化:v1 审计(novelty 6,borderline)→ v2 重定位+设计加固(overall 6,仍卡 borderline,因实验未跑)→ **v3:换动态 headline 拿 novelty 7 + 便宜可跑实验核抬总分,同时保留 v2 全部加固**。目标:novelty=7、overall~7、实验 M1 可跑不难。novelty 7 conditional on 核心实验显示"检测性随深度衰减"(唯一 kill-switch,几天可测)。

---

## 0. 一句话主张
**迭代记忆固化(C^N 递归摘要)不是被动的保真压缩——它是一个把"初始可检测的关系/角色错误"随深度主动驱入所有 overlap-kernel 评测器盲区的过程;盲区不是评测器偶然的静态缺陷,而是固化动力学的稳定吸引子。**

## 1. 动机 / 瓶颈(为什么这是 novelty 而非审计)
"标准评测器(NLI/SummaC/LLM-judge)盲于关系/角色误绑"是**静态**事实,已被 HANS'19 / FRANK'21 / INFUSE(2402.17630) / BUMP(ACL'23)占先——审计它只值 novelty 6。开放且无人占据的是**动态**问题:**记忆系统自己的固化操作,会不会随深度把一个本来可检测的错误,主动洗成检测器认证"faithful"的形态?** 这把问题从"评测器有洞"(谁都能说)挪到"**压缩过程会主动制造并隐藏错误**"——6→7 的相变。

## 2. 三个贡献
- **C1(headline · 经验 · 便宜)**:首次证明并量化**固化深度导致可检测关系错误变得检测器不可见**——种入一个 N=0 可被抓到的角色错误,固化到 N=1..8,测**检测器 recall 随 N 的衰减曲线**;跨检测器族、跨数据集(HaluMem/LoCoMo/LongMemEval)。机制:固化压缩**丢弃跨句消歧上下文**,错误仍在、检测器再也判不出(与本项目已发现的"固化丢跨句消歧"一致)。
- **C2(机制 · 轻形式)**:**overlap-kernel blind cone** —— 任何"支持信号随源-记忆词/跨度 overlap 单调"的 scorer,对**保持论元多重集的角色置换**在证明上不可分辨(一个 overlap-monotonicity lemma);把 C1 的经验衰减解释为固化在该 kernel 度量下对角色错误对的**收缩映射**,吸引子落在 cone 内。形式只作 motivation,不作 load-bearing。
- **C3(后果 · scoped)**:这些被深度洗白的错误被 **HaluMem relationship-memory slice 的官方 judge 认证 faithful** → benchmark faithfulness 通胀;只在 checker-vs-judge 分歧子集上做轻量 human-gold 锚定,report false-SAFE 方向 + CI。

## 3. 方法(M1 可跑、不难、无下载/无重 human-gold/无重定理)
**核心实验(= kill-switch,最先跑)**:复用现有 C^N harness + S1 种子套件(`rq2_seed_taxonomy.py`)+ 盘上 DeBERTa-MNLI/SummaC。
1. 种入**在 N=0 可检测**的角色错误(源含消歧句,检测器 recall≈1);
2. C^N 固化到 N∈{0,1,2,4,8};
3. 测**每个检测器 recall vs N** → 主结果 = recall 随 N 显著下降(McNemar over depth,Clopper-Pearson CI)。
**加固控制(承接 v2)**:
- **windowing 控制**:把完整多句上下文 in-window 喂给 per-sentence NLI → 剥离"证据出窗"混淆,只把"in-window 仍随 N 掉"归因于固化洗白;
- **负控**:同错误去 overlap → N=0 检测器 recall 回 ~1,gap 消失(锚定 lexical-overlap 机制);
- **relation-aware baseline**:SRLScore/QASem/MiniCheck 纳入(可离线的先跑,需下载的标注为可选扩展),预承诺诚实报告"若它们不随 N 掉,则洗白只对 overlap-kernel 类成立";
- **统计预注册**:paired McNemar、bootstrap CI、Holm/BH、≥150 对/格。
- **RoleE 形式定义** + 精确 overlap 度量(content-unigram overlap ∧ 不引入源外词,+BERTScore-precision)。

## 4. Falsification(锁定,便宜可判)
主预测 = 检测器 recall 随固化深度 N 单调下降(McNemar p<.01),而错误内容仍在(用 provenance 确认错误未被修复只是被隐藏)。**负控** = 去 overlap 后 recall 不随 N 掉(错误始终可检)→ 证实是"洗向 overlap 盲区"而非泛化遗忘。**若 recall 不随 N 下降**,C1 与 novelty-7 主张经验上被证伪。

## 5. Kill-switch(唯一诚实前提)
novelty=7 与总分~7 都 conditional on **§3 核心实验显示 recall 随 N 衰减**。这**几天内、M1、离线可测**。
- 衰减成立 → novelty 7(动态、无人占据)+ 真实验曲线(exp_validation 抬起,总分→~7)+ 全程 easy;
- 不衰减 → 诚实退到**静态测量矩阵**(固化深度×关系类型×评测器族三维盲区 + CI,纯经验、M1 可行,但 novelty 回落 ~6.5)。**先跑,再决定押不押动态 headline。**

## 6. Compute
单 M1 + <$50 API;核心实验纯 inference、CPU(MPS 长前提会挂)、per-session qdrant path、Clopper-Pearson 小 n。人工只需分歧子集轻量 gold(报 κ)。几天。无 GPU 训练、无模型下载(核心)。
