# RQ2 自建版固定协议（2026-07-07）

这份协议只对应 **自建版** `RQ2`。它的作用是把范围收口，避免后面继续一边跑一边换题、换问法、换口径。

## 1. 固定范围

自建版当前只保留这三个家族：

1. `classification`
2. `security`
3. `config`

暂时 **不再新增** 其他家族，不再扩新题。

## 2. 固定设置

- 套件版本：`v2`
- 重复次数主设置：`repetition = 3`
- 主要问法：
  - `free`
  - `operational`
- 主要后端：
  - `prompt_only` 负责机制主信号
  - `tiermem` 负责看记忆系统内的保留/放大/修复模式

## 3. 固定问题

自建版现在只回答这两个问题：

1. **重复错误团队说法，会不会把模型带偏？**
2. **带偏之后，进入 TierMem，不同家族会不会呈现不同的深度轨迹？**

暂时 **不再硬问**：

- “固化一定越深越糟吗？”

因为当前数据已经说明，这不是统一成立的。

## 4. 固定输出

每次新的自建版评估，都至少要产出四样东西：

1. 家族 × 深度 × seed 的汇总表
2. 逐题表
3. 待人工复核 CSV
4. 官方版 / 自建版分线摘要

## 5. 固定优先级

以后继续推进时，优先顺序固定为：

1. 先复跑现有家族
2. 再做逐题分析
3. 再做人审
4. 最后才考虑扩题或扩家族
